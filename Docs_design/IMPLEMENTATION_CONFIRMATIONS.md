## 回答を待たずに修正したレビュー指摘

- ADCの保存先上書き、MAP/水温/A/F/ノックの入力不一致、温度による誤アイドル判定を是正。
- TIM2更新を0.5msから1msへ変更。PC10/PB7の試作用トグルを無効化し、LD2のみ100msごとのトグルを維持。
- ビルドは外部STM32CubeF4 v1.28.2を明示して利用可能にし、欠落時に必要な設定を表示。依存SDKは同梱せず、READMEに再帰取得手順を追加。

## 内部APIの扱い

追加モジュールは値の供給・校正を呼出し元に要求する。未設定の校正、非有限値・ゼロ除算・重複軸・無効入力は成功としない。入力異常時の代替燃料・点火値は生成しない。
`ecu_fuel`の質量単位は入力空気質量とインジェクタ質量流量で一致させる。燃料密度を含む体積流量→質量流量の変換はQ05/Q06の回答待ち。
テーブルは呼出し中に変更しない読取り専用配列を受ける。永続化／マップ更新を実装する際、停止中のみの変更と値域検証を設定管理層で保証する。
