# NE・G1・G2同期方式の検討

## 資料と読み取り範囲

2026-10-18提示の整備書写真（図A05124）を対象とする。測定条件は暖機後のアイドル、2 V/DIV、20 ms/DIV。CH1=G1−G−、CH2=G2−G−、CH3=NE−G−。写真は交流の磁気ピックアップ波形であり、MCU入力の論理レベルを示すものではない。

- G1の次にG2、次にG1が現れる。G1→G2とG2→G1はおおむね等間隔。
- 各区間にはNEが約12周期、G1→次のG1には約24周期あるように読める。写真の解像度と歪みがあるため、厳密な歯数・位相の確定値にはしない。
- 既存要求のNE=12パルス／クランク1回転を前提にすると、G1とG2の間は360°、同じGの繰り返しは720°クランク角（カム1回転）と解釈できる。写真の読み取りと、以下の要求確定を区別する。
- 図にはTDC位置・角度目盛り・整形後の波形がない。G1=#1、G2=#2という対応と、選択したNEエッジが正確にTDCという関係は、この写真だけでは証明できない。

## 2026-10-18の要求確定と設計前提

要求者の決定により、G1/G2はそれぞれカム1回転（720°クランク角、NE 24周期）に1回と確定する。従来の「カム2回転に1回」という暫定解釈を訂正する。これはプロジェクトの要求確定であり、入力回路の完成・実測を意味しない。

調査資料では[EP Wiringの4E-FTE設定例](https://ep-wiring.com/en-int/pages/4e-fte-wiring-ecu-configuration-information)がカム位置の24歯とCam Pulse 1xを示す。[Link ECUの4efteスレッド](https://forums.linkecu.com/topic/9609-4efte/)では、同期用1歯をG1/G2の2センサーが検出し、どちらか一方を同期入力に使用できると説明している。これらは気筒番号やTDC角度差の確定根拠とはしない。

ソフトウェアは、整形後のNE立下りを角度刻みとし、その立下り時に該当するG1/G2がHiとなるよう入力回路で整形する前提で設計する。Gの独立エッジを時刻キャプチャしてNEに対応付ける従来案から、NE立下り時のGレベル判定を基本案に更新する。欠け歯がないNE単独では、絶対角度・気筒位相は復元できない。

整形回路のゼロクロス方向、反転、遅延を選び、MCUで採用するNE立下りとGのHi期間の対応を成立させる。正負両側の生波形を別々の歯として数えない。GのHi幅の具体値は残件とし、以下の境界条件に従って回路を設計する。

### 位相テーブル

G1がHiのときのNE立下りを便宜上index=0とし、0〜23で循環する。G2はindex=12に対応することを設計上の期待値とする。気筒対応・点火順序は確認中のため、位相indexと気筒番号を別の設定として管理する。

| 歯index | NE立下り時の期待レベル | 位相基準 |
|---|---|---|
| 0 | G1=Hi、G2=Low | G1基準 |
| 1〜11 | G1=Low、G2=Low | NEで位相を追跡 |
| 12 | G1=Low、G2=Hi | G2基準 |
| 13〜23 | G1=Low、G2=Low | NEで位相を追跡 |

NEの刻みは30°クランク角。index=0のNE基準から#1圧縮TDCまでの進行角をδと定義し、各基準歯の角度を `(30° × index − δ) mod 720°` とする。δ=0を写真から確定しない。実測でG1/G2に対する歯の対応と気筒番号を検証する。

### TDCオフセットの校正構造（採用）

要求者の決定により、上記の基準NE歯から実際の#1圧縮TDCまでの角度差を後から校正できる構造を採用する。本案ではG1がHiのときのNE立下りをindex=0とする便宜上の規則を維持し、G1を#1気筒に対応すると固定しない。

- δの単位はクランク角度、正方向はエンジンの正転方向とする。基準NE歯から次の#1圧縮TDCまでの進行角として、`0° <= δ < 720°` に正規化する。基準歯が#1圧縮TDCと一致すると実測で確認できた場合に限りδ=0°とする。
- 角度変換後の0°を#1圧縮TDCとする。上記のmodは結果が0°以上720°未満となる剰余を表す。δの小数部も表現できる設計とし、NE歯間の30°単位に校正を限定しない。具体的な分解能・データ形式は詳細設計で決める。
- 例えばδ=20°なら基準NE歯は#1圧縮TDCの20°手前、δ=380°なら360°異なる行程側の基準となる。これらは定義を説明する例であり、4E-FTEの校正値ではない。
- デコーダの位相indexと校正後のエンジン角度を分離し、噴射・点火スケジューラへは共通の校正後角度を渡す。δを変更してもNE/Gの歯数・並びの判定方式は変えない。
- δは設定パラメータとして管理し、未校正であることを識別できるようにする。変更はエンジン停止中に行う。具体値は#1圧縮行程の確認と角度測定で決定し、構造設計は校正前から進める。

### NE立下りとGレベルの対応付け

NE立下り時刻をタイマ入力キャプチャ等で記録し、そのイベントに対応するG1/G2のレベルを取得する。G信号は次の条件を満たすよう入力回路で整形する。

1. 対象のNE立下りより前に該当GをHiとし、レベル取得が完了するまで安定して保持する。Hi開始・終了をNE立下りと同時に切り替えることを前提にしない。
2. 同じGのHiを隣接するNE立下りでも検出することがない幅とする。各GパルスをNE歯に一意に対応付ける。
3. 対象NE立下りでは反対側のGはLowとする。両方Hiは不正な入力として扱う。

NE時刻のハードウェア記録とGレベルのソフトウェア読取りは同時ではない。割込み遅延・読取り時間・入力回路の遅延差を考慮して前後の余裕時間を決める。G1/G2の取得時刻差も制限し、同一GPIOポートの一括取得等を検討する。具体的なHi幅・余裕時間・許容遅延は未定とするが、この境界条件でデコーダ設計を進める。NEイベントの時刻とGレベルを一組として扱い、処理の遅延やキャプチャ欠落により別のNE歯のレベルを誤って対応付けないこと。

### 状態遷移案

1. **未同期:** 有効なNE間隔から回転数を推定する。絶対位相は無効。
2. **仮同期:** NE立下り時にG1またはG2の一方だけがHiなら対応NE歯の候補を決める。G1ならindex=0、G2ならindex=12を候補にできる。
3. **確認:** 次の反対側のGを12歯後、次の同名Gを24歯後のNE立下りで検出することを確認する。初期案ではG1→G2→G1またはG2→G1→G2の確認後に同期成立とする。各NE立下りを一度だけ数え、同じ歯を二重計数しない。
4. **同期中:** NEごとにindexを更新し、期待するG1/G2のレベルと歯数を照合する。G検出のたびに無条件でindexを上書きして異常を隠さない。
5. **同期喪失:** 歯数／G種類の不整合、期待しない歯でのHi、両G同時Hi、NE欠落、入力停止、キャプチャオーバーラン等で位相を無効化し、未同期から取得し直す。G欠落は期待するNE歯でHiを取得できなかった場合に判定する。

確認に必要なのは最初の有効Gから最大720°であり、回転開始から最初のGを待つ時間が別途加わる。許容する始動遅延に応じて確認条件はベンチ評価後に見直す。

NEの短すぎる間隔はノイズ候補、長すぎる間隔は欠落候補とする。ただしクランキングの圧縮変動や急加減速もあるため、固定の周期比だけで確定判定しない。許容値・連続異常回数は実測から決める。停止判定は要求者決定により、最後の有効なNE入力から固定時間T_stopが経過した場合とする。T_stopは設定パラメータとし、具体値は未定。直前のNE周期・回転数には連動させず、棄却したノイズエッジではタイムアウトを延長しない。詳細は[要求仕様書5.1.2](ECU_Requirements_Specification.md#512-クランキング中と始動後の噴射制御2026-10-18)に記載する。停止タイムアウト前の欠落・同期喪失判定と出力動作は別途決定する。位置を失った後に歯を推測して同期を維持しない。

同期状態と出力許可は分離する。本検討は同期デコーダの提案であり、既存要求書にある未決定の同期喪失時の噴射・点火動作を変更・承認するものではない。

要求者決定により、NE入力とG1/G2の対応が正常な場合は、500 rpm未満になっても取得済みの720°位相を保持し、NE/Gによる位相追跡と整合性確認を継続する。回転数低下による噴射方式の変更だけでは位相index・同期成立情報をリセットしない。正常な同期が継続している場合、500 rpm以上への復帰で同期を取り直す必要はない。停止判定時とNE/G不整合時の同期の扱いは、それぞれの条件に従う。

停止判定時の初期化は要求者決定により、同期情報・噴射周期カウンタ・初回噴射待機カウントをリセットする。再始動では停止前の位相indexとNE周期履歴を引き継がず、NEから回転を再確認して720°位相を取得し直す。全数同時噴射方式を継続する場合、初回は回転再確認後12 NE周期を待って行う。起動・再始動・低回転復帰のいずれでも、待機中に500 rpm以上かつ有効な720°位相が成立した場合は待機を解除して角度指定グループ噴射へ切り替える。停止判定時は噴射中のパルスも即時終了し、未開始の噴射予約を取り消して新規噴射を禁止する。停止前の噴射イベントを再始動後に適用しない。点火出力・点火予約の扱いは要求仕様書の残件とする。

## STM32での構成案

NEはタイマ入力キャプチャを優先し、G1/G2はNEイベントに対応するGPIOレベルを取得する構成を基本案とする。Gの独立した入力キャプチャは基本案の必須条件にしない。具体的なピン・AF・タイマ構成は未選定。NE割込みからG読取りまでの最大遅延が入力整形の保持時間内に収まることを設計・検証する。

NE=12パルス／クランク回転なら、回転数は `rpm = 60 / (12 × T_NE秒)`。7000 rpmでNEは1400 Hz、歯間は約714 µs。1 MHzの時刻基準なら1 tickはこの回転数で約0.042°に相当するが、これは量子化の目安であり、入力回路の誤差や歯間補間誤差を含む角度精度ではない。低速・停止時のカウンタ周回、キャプチャ欠落も扱う。

歯間の任意角度は直近NE周期等から補間し、出力比較タイマに予約する。クランキング時の角速度変動に対する精度は別途検証する。

## 残る測定とベンチ確認

- 確定した同名G間24周期という要求と、異名G間12周期という期待値が入力で成立することを、複数サイクルで確認する。
- 生波形と整形後3信号を対応付け、対象NE立下りの前後のGのHi余裕時間、レベル取得遅延、隣接歯での非検出、回転数による遅延変化を測る。
- #1圧縮TDCの独立基準と比較し、δ、G1/G2の気筒対応、ディストリビュータ調整の影響を確認する。
- 任意の歯からの開始、G2先着、クランキング変動、加減速、GのHi幅不足・過大、読取り遅延、両G同時Hi、ノイズ、各信号欠落・余分なパルス、停止・再始動、タイマ周回を模擬入力で試す。
- 合格条件は、正しい並びでのみ同期し、1歯ずれ・360°ずれを同期成立として受理しないこと。不整合時の位相無効化と再取得をログで確認する。

上記の確定周期と入力整形条件を前提にソフトウェア設計を進める。気筒対応・TDC角度差と判定の数値条件を設定として分離し、実測・ベンチ確認で確定する。本更新は要求・設計文書への反映であり、デコーダのコード実装は含まない。
